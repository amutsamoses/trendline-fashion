# TrendLine Fashion

A modern, responsive multipage fashion website showcasing the latest trends from 2024-2026.

## Features

### Home Page
- **Hero Section**: Full-width animated gradient background with catchy headline and CTA
- **Featured Collections**: Showcase of 6 curated fashion collections for 2024-2026
- **Call-to-Action Section**: Engaging CTA encouraging visitors to explore or contact
- **Responsive Navigation**: Sticky header with mobile-friendly hamburger menu
- **Footer**: Comprehensive footer with quick links, customer service, social media, and newsletter subscription

### Technical Highlights
- ✅ Fully responsive design (desktop, tablet, mobile)
- ✅ Smooth scroll animations and transitions
- ✅ Interactive hover effects on collection cards
- ✅ Mobile navigation toggle with hamburger menu
- ✅ Newsletter subscription form
- ✅ Active navigation link highlighting based on scroll position
- ✅ Accessibility features (ARIA labels, keyboard navigation)
- ✅ Parallax scrolling effects
- ✅ Animated gradient hero background

## Getting Started

### Viewing the Website

Simply open `index.html` in your web browser, or serve it using any local HTTP server:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js (with http-server package)
npx http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.
