# TrendLine Fashion

A modern, responsive product showcase website highlighting Men's and Gen Z fashion trends from 2024 to 2026.

## 🌟 Project Overview

TrendLine Fashion is a professional fashion showcase platform featuring multiple pages designed to present contemporary fashion trends in a clean, accessible format. The website demonstrates modern web development practices with HTML5, CSS3, and JavaScript.

## 📋 Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Multiple Pages**: 
  - Home - Hero section with featured collections
  - About - Brand story and mission
  - Collections - Curated fashion trends (2024-2026)
  - Gallery - Visual showcase of products
  - Contact - Contact form and information
- **Interactive Navigation**: Mobile-friendly menu with smooth animations
- **Modern UI/UX**: Clean design with gradient accents and smooth transitions
- **Form Validation**: Client-side validation for the contact form
- **Scroll Animations**: Elements animate into view as you scroll

## 🚀 Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with Flexbox and Grid
  - CSS Variables for consistent theming
  - Responsive design with media queries
  - Smooth animations and transitions
- **JavaScript (Vanilla)**: Interactive features
  - Mobile menu toggle
  - Form validation
  - Scroll effects
  - Intersection Observer API for animations

## 💻 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/amutsamoses/trendline-fashion.git
   ```

2. Navigate to the project directory:
   ```bash
   cd trendline-fashion
   ```

3. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

4. Visit `http://localhost:8000` in your browser
